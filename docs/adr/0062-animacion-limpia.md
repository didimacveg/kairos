# ADR 0062 — Menos elementos, mejor tiempo

**Estado:** aceptado · **Fecha:** Fase 62

## Cuarta version
Las anteriores acumulaban elementos —chispas, rayos, rejillas, barridos—
asumiendo que mas piezas era mas impresionante. El resultado era ruido: a esa
velocidad no se distinguia nada y todo competia por la atencion.

Esta tiene SEIS elementos y una sola idea: un punto que se carga, rompe en un
anillo, y deja la marca.

## Lo que la hace buena es el tiempo, no la cantidad
- la carga late tres veces — tension antes del suceso
- la rotura es instantanea, el 14% de la duracion
- la marca aparece con calma y se queda el 60% del tiempo

Una animacion de sistema debe leerse como una afirmacion, no como fuegos
artificiales. Las versiones anteriores gritaban; esta afirma.

## El disparador discreto
Un punto casi invisible abajo a la derecha en la pantalla negra, y Espacio o
Enter como atajo.

Para cuando se graba solo y no se puede decir la frase en alto —porque estas
narrando otra cosa, o porque el audio se graba aparte. En camara no se
distingue de un pixel muerto.
